## [1.0.0] - 2026-10-18

The first tagged release.

### Added

- Guides for building a full-stack web app, by layer: frontend, backend, API,
  and database.
- Copy-paste prompts that pin a stack.
- RAG and persistent context guides, with an importable n8n workflow.
- Agent skills for connecting an MCP server, adding tests, a pre-deploy check, and
  explaining an error.
- Rescue guides for when something breaks.
- A "For writers" pointer to Context for AI and the Harness Engineering Cookbook,
  and a "Link to a stable version" section in the README.
- `SECURITY.md`, `CITATION.cff`, `VERSIONING.md`, a markdownlint check in CI, and
  vendor-neutral and verified-figures items in the pull request checklist.

### Changed

- The starter tutorial and its n8n workflow work with any MCP server that supports
  streamable HTTP. The MCP Studio steps sit in a disclosed, collapsible block.
