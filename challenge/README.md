# The 7-day ship it challenge

Build and publish one small AI project in seven days. Not a startup, not a perfect
app: one useful thing, live on the internet, that you built with AI tools and
understand.

## How to join

1. Post in [Discussions](https://github.com/zthewriter/ship-with-ai/discussions) under
   **Show and tell** with the title "Day 0: [what you want to build]".
2. Reply to your own post each day with what you did and one thing you learned.
3. On day 7, share the link to your live project.

Stuck? Ask in the thread. Someone will help.

## The days

### Day 1: pick something tiny

Choose a project you can describe in one sentence, for one person you know. Good
examples: a chat assistant for your club's rules, a tool that summarizes your notes,
a page that answers questions about your product.

- [ ] Write the one sentence
- [ ] Name the one person it is for

### Day 2: give it a memory

- [ ] Read [What RAG is](../docs/01-what-is-rag.md)
- [ ] Gather the content your project should know
- [ ] Follow [Build your first AI assistant](../docs/04-build-your-first-assistant.md)
      or connect your content another way

### Day 3: build the first version

- [ ] Build the smallest version that does the one thing
- [ ] Ask it five real questions and write down what went wrong

### Day 4: save your work properly

- [ ] Put your project in a GitHub repository
- [ ] Make one change through a branch and a pull request
      ([How shipping works](../docs/05-how-shipping-works.md))

### Day 5: add one safety net

- [ ] Install the [add-tests skill](../skills/add-tests/SKILL.md) and add one test,
      or write a checklist of five things to try before each change

### Day 6: go live

- [ ] Run the [pre-deploy-check skill](../skills/pre-deploy-check/SKILL.md)
- [ ] Deploy it, and set a spending limit on every service with your card

### Day 7: share it

- [ ] Send it to the person from day 1
- [ ] Post the link, and what you would do next, in your thread

## Rules

- Small beats impressive.
- You can use any tools.
- Be kind in other people's threads. Everyone here is learning.
